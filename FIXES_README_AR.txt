إصلاح نهائي لمسار الإشعارات ورسائل الإدارة

1) الإشعارات العادية تستخدم notif_center + notif_center_views.
2) رسائل الإدارة تستخدم user_messages + user_message_reads.
3) زر "مين شاف" للإشعارات يقرأ notif_center_views.
4) سجل رسائل الإدارة يقرأ user_message_reads باستخدام read_at.
5) زر "حسنًا، فهمت" فقط هو الذي يسجل قراءة رسالة الإدارة؛ لا يتم تسجيلها عند مجرد ظهورها.
6) max_views يتم احترامه باستخدام view_count.
7) إشعار النشر التلقائي يستخدم نفس RPC الخاص بالإشعارات العادية، لذلك لا يتم خلطه مع رسائل الإدارة.

مهم: شغّل SQL_NOTIFICATION_FINAL.sql مرة واحدة في Supabase SQL Editor قبل الاختبار.
