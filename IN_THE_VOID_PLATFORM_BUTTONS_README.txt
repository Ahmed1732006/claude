IN THE VOID — أزرار الروابط السريعة

سبب خطأ "Could not find the 'device_mode' column ... in the schema cache":
النسخة السابقة أضافت ميزة الأجهزة إلى الكود، لكن قواعد البيانات التي كان فيها جدول platform_buttons قديمًا لم تحصل على العمودين placement وdevice_mode.
الإصدار الحالي يحتوي على ALTER TABLE آمن بـ IF NOT EXISTS لإضافة الأعمدة والقيود، ثم يطلب من PostgREST إعادة تحميل الـschema cache.

التفعيل:
1) افتح Supabase > SQL Editor.
2) انسخ/شغّل ملف IN_THE_VOID_PLATFORM_BUTTONS.sql كاملًا مرة واحدة.
3) انتظر ثواني قليلة ثم أعد تحميل الموقع (ويُفضّل Hard Refresh).
4) بعدها جرّب حفظ الزر.

الميزات:
- واتساب وتليجرام جاهزان وقابلان للتعديل.
- الاسم والصورة والرابط اختياريون.
- الجمهور: الكل / أشخاص محددون / الأعضاء / المشرفون / الأدمن.
- مكان الظهور: بره ملك المنصة / جوه / الاثنين.
- الأجهزة: الموبايل والكمبيوتر / الموبايل فقط / الكمبيوتر فقط.
- ترتيب الأزرار بأسهم ↑ ↓.
